An end-to-end customer retention strategy for a fictional online travel platform: a multi-level scoring model segments users into distinct groups (business travelers, budget-conscious bookers, high-value VIPs), each mapped to a tailored perk. The work spans data modeling in PostgreSQL, analysis in Python, and a C-level presentation translating the segmentation into a concrete rewards program design.

**Tech Stack:** PostgreSQL · Python (Pandas, NumPy, scikit-learn, Matplotlib/Seaborn) · Tableau · Data Storytelling

**Highlights**

* Custom data model and scoring logic built directly in PostgreSQL
* Customer segmentation translated into a personalized rewards program per segment
* Findings distilled into a management summary and a C-level presentation deck
* Identified the manual scoring model's limitations and scoped k-means clustering as the next iteration
